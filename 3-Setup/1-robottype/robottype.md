## 3.1 设置机器人类型和附加轴数量

附加轴的设置按以下顺序进行：

(1) 导航到 [System] → [5: Initialization] → [2: Robot type selection] 并选择机器人类型。

{% hint style="info" %}
要配置机器人类型和附加轴参数设置，必须输入工程师代码 (R314)。显示器屏幕右上角的“e”指示灯确认工程师代码已输入。
{% endhint %}

(2) 输入附加轴的数量并按“OK”，然后重启控制器。
